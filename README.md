# Face LoRA Dataset Selector

用于人物 / 人像 AI 训练数据集的本地整理与筛选工具。

面向以人物图片为训练素材的 LoRA、模型等训练任务，提供数据集分析、筛选与优化流程。

自动分析、评分、排序和推荐可以减少大量重复的人工筛选工作；如果你追求更高质量、更精细或更个性化的数据集，也可以在自动分析基础上高效率地进行人工复筛。

**Windows · 本地运行 · 解压即用 · 轻量快速**

## 它能做什么？

**轻量、本地、解压即用**

Windows 本地运行，下载解压即可使用。

**自动推荐**

只需选定文件夹，并设定好目标数量，即可通过评分与推荐系统自动批量推荐图片。

**快速分析**

采用轻量、成熟的分析方案，大批量素材也能快速完成处理。

**科学的筛选系统**

参考权威公开研究、论文和经过验证的模型，结合 AI 训练需求进行评分、排序与推荐。后续版本会持续调整迭代。

**高效手动筛选**

快速方便地调整挑选结果，自由决定最终选择。

**组合图自动拆分**

自动识别多人物、多视角和拼接图片，并生成拆分结果供快速确认。

**自动裁剪**

自动识别人物主体，并裁掉图片中的无效区域，支持人工确认和调整裁剪范围。

**批量自动去文字 / 水印**

自动批量检测图片中的文字和水印区域，支持预览、人工调整和批量处理。

**非破坏性文件操作**

处理结果与原始数据分离，不直接覆盖原始图片。

## 适合哪些数据集？

不管你是第一次准备自己的 LoRA，还是已经长期在做 AI 生图、LoRA 训练或模型微调，只要素材主要是人物 / 人像图片，这套流程都可以用来做训练前整理。

例如：

- 真人 / 人物身份 LoRA；
- 更强调脸部特征的数据集；
- 身材、体型、身体比例相关训练；
- 服装、造型、角色外观 LoRA；
- 以人物为主体的摄影、视觉或其他风格训练；
- 其他需要人物图片筛选、去重、裁剪、拆分和人工复核的数据集。

如果你的数据完全不依赖人物信息，例如纯场景、纯产品或其他非人物数据集，当前的人脸、姿态和景别指标就不一定合适。

## 主要功能

### 数据集分析与筛选

程序会整理人脸质量、整图质量、头部朝向、身体可见范围和近重复关系，并把结果放到同一个浏览和筛选界面里。

你可以继续按自己的训练目标筛选、排序和修改结果，不需要被一个总分牵着走。

### 近重复处理

连拍、视频抽帧和同一套写真里经常会出现大量几乎一样的图片。

程序会先找出近重复素材，再结合质量信息帮助比较，减少在同一组图片里来回翻看的时间。

### 组合图拆分 · v0.3

多视角、多人物或拼在一起的素材，可以先生成拆分候选，再由你决定哪些区域真正值得保留。

不会因为检测到多个人，就自动把所有区域都塞进训练集。

### 自动裁剪 · v0.3

对需要收紧构图的图片给出裁剪建议，并允许手动调整 ROI。

裁剪建议不会直接改写源图；最终导出训练集时，接受的裁剪才会写入输出图片。

### 字幕 / 水印 / 文字清理

Text Cleanup 会检测图片里的文字区域，也可以手动增删检测框。

支持 TELEA、Navier-Stokes 和可选的 MI-GAN AI 修复。可以先看预览，再批量输出到新目录。

### 整理与导出

完成筛选后，可以把最终保留的素材导出为训练集。

v0.3 还增加了独立的源文件整理流程；真正移动文件之前会先给出计划和提示。

## 一个典型的整理流程

v0.3 的完整流程大致是：

```text
原始人物素材
      ↓
初始分析与筛选
      ↓
近重复复核
      ↓
组合图拆分
      ↓
自动裁剪 / 人工调整
      ↓
源文件整理（可选）
      ↓
导出训练集
```

Text Cleanup 是独立功能，需要处理字幕、水印或图片文字时再使用。

v0.2.0 已经可以完成核心分析、筛选、近重复检测、文字清理和导出；组合图拆分、自动裁剪和源文件整理属于 v0.3 新增流程。

## 为什么不直接按“质量分数”选前 N 张？

因为人物训练数据里，单张图片质量高，不代表整套数据就合适。

只看总分，很容易最后留下来的几乎全是正脸大头照，或者同一套连拍占了一大半。对于身材、服装、角色外观等训练目标，这种偏科同样会影响数据覆盖。

这里会把几个问题分开看：

```text
图片是否基本可用
→ 人脸与整图质量
→ 近重复
→ 头部角度
→ 景别 / 身体可见范围
→ 人工确认
```

这些分析只是帮你更快看清数据里的问题，最后怎么取舍还是按自己的训练目标来。

## 快速开始

### 整理人物训练数据集

1. 选择图片目录并完成初始分析。
2. 先处理明显差图和近重复素材。
3. 看一下不同角度、景别和身体可见范围是否过于集中。
4. 按自己的训练目标继续人工筛选。
5. 最后导出真正要用于训练的图片。

如果使用 v0.3 开发版，还可以在同一流程里继续处理组合图和自动裁剪。

人物一致性、表情、服装、姿态、身材、画面风格，以及你希望最终模型学到什么，仍然需要自己判断。

### 清理字幕 / 水印

选择输入目录后，程序会检测文字区域。可以修改检测框、选择修复方式、先看预览，再批量输出到新目录。

如果文字正好覆盖眼睛、五官或其他重要训练特征，很多时候直接不用这张图会比强行修复更合适。

## 分析用了什么？

不同问题由不同方法处理：

| 用途 | 方法 |
| --- | --- |
| 人脸检测 | YuNet |
| 人脸质量 | eDifFIQA-T |
| 整图质量 | BRISQUE |
| 头部姿态 / Yaw | 3DDFA-V2 |
| 身体关键点 / 景别辅助 | MediaPipe Pose |
| 近重复 | pHash + 质量排序 |
| 文字区域检测 | PP-OCRv5 |

这些指标负责提供信息和候选排序，不会单独决定一张图片最终该不该进入训练集。

相关项目与资料：

- [eDifFIQA](https://github.com/LSIbabnikz/eDifFIQA)
- [BRISQUE / OpenCV Quality](https://docs.opencv.org/4.x/d8/d99/classcv_1_1quality_1_1QualityBRISQUE.html)
- [3DDFA-V2](https://github.com/cleardusk/3DDFA_V2)
- [YuNet / OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)
- [MediaPipe Pose Landmarker](https://developers.google.com/mediapipe/solutions/vision/pose_landmarker)

## 原图和文件安全

大多数工作流不会覆盖原始图片。

分析结果、筛选状态、自动裁剪建议、训练导出和 Text Cleanup 修复都会保存在缓存或新的输出位置。

v0.3 中有两类操作会改变文件位置，因此会明确提示：

- 接受组合图拆分后，原组合图会移动到数据集内的隔离目录；
- 使用 Source Organizer 时，会在确认计划后移动活动图片。

第一次使用这类文件整理功能时，建议先用数据集副本熟悉流程。

## 模型下载与缓存

大部分基础功能所需的模型会随程序提供。

少数可选功能会在第一次使用时按需下载模型，例如 MI-GAN。下载完成后会校验并保存到 FaceLoRA 的模型缓存中，后续可以继续复用。

可选模型下载失败不会影响与它无关的其他功能。

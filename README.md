# Face LoRA Dataset Selector

一个用来整理 **人物 / 人像训练数据集** 的 Windows 桌面工具。

无论你是第一次准备自己的 LoRA，还是已经长期在做 AI 生图、LoRA 训练或模型微调，只要手里的训练素材主要是人物图片，就很容易碰到同一类问题：图太多、重复太多、角度和景别失衡、拼图要拆、水印要清、构图还得重新裁。

Face LoRA Dataset Selector 把这些训练前的整理工作放到一个本地流程里。自动分析负责帮你缩小范围，最后哪些图片进入训练集仍然由你决定。

## 什么时候会用到它？

它并不只针对“人脸 LoRA”。

你可以拿它整理人物身份、人脸特征、身材 / 体型、服装造型、角色外观，以及以人物图片为主体的摄影或视觉风格数据集。只要你的素材需要做人物图片筛选、去重、裁剪、拆分或人工复核，这套流程都可能派上用场。

比较常见的情况有：

- 收集了几十、几百甚至更多张图片，需要先筛出值得继续看的部分；
- 素材来自连拍、视频抽帧、写真图集，同一场景里有大量近重复图；
- 正脸很多，但 3⁄4、侧脸、半身、全身明显不足；
- 想训练身材、服装或角色外观，却发现数据里大头照占比过高；
- 图片里混有多宫格、多人物、字幕、水印或不理想的构图；
- 已经有自己的数据集标准，只想用自动分析减少重复劳动，而不是让软件替你做最终决定。

## 主要功能

### 数据集分析与筛选

程序会分析人脸、画面质量、头部朝向、身体可见范围和近重复关系，再把结果整理成更容易查看的候选。

这些指标不是为了给图片下一个“绝对好坏”的结论，而是为了让你更快发现明显差图、重复图和数据覆盖上的问题。

### 近重复处理

连拍、视频抽帧和同一套写真里经常会出现大量“几乎一样”的图片。

程序可以先找出这些近重复素材，再结合质量信息帮助比较，减少同一组图片来回翻看的时间。

### 组合图拆分 · v0.3

多视角、多人物或拼在一起的素材，可以先生成拆分候选，再由你决定哪些区域真正值得保留。

不会因为检测到了几个人，就自动把所有区域塞进训练集。

### 自动裁剪 · v0.3

对需要收紧构图的图片给出裁剪建议，并允许手动调整 ROI。

裁剪建议不会直接改写源图；最终导出训练集时，接受的裁剪才会写入输出图片。

### 字幕 / 水印 / 文字清理

Text Cleanup 可以检测图片中的文字区域，也可以手动增删检测框。

支持 TELEA、Navier-Stokes 和可选的 MI-GAN AI 修复，可以先预览，再批量输出到新目录。

### 整理与导出

完成筛选后，可以把最终保留的素材导出为训练集。

v0.3 还增加了独立的源文件整理流程；真正移动文件之前会先给出计划和提示。

## 一个典型的整理流程

v0.3 的完整流程大致是：

```text
原始人物素材
      ↓
初始分析与筛选
      ↓
近重复复核
      ↓
组合图拆分
      ↓
自动裁剪 / 人工调整
      ↓
源文件整理（可选）
      ↓
导出训练集
```

Text Cleanup 是独立功能，需要处理字幕、水印或图片文字时再使用。

v0.2.0 已经可以完成核心分析、筛选、近重复检测、文字清理和导出；上图中的组合图拆分、自动裁剪和源文件整理属于 v0.3 新增流程。

## 为什么不直接按“质量分数”选前 N 张？

因为人物训练数据里，单张图片质量高，不代表整套数据就合适。

只看总分，很容易最后留下来的几乎全是正脸大头照，或者同一套连拍占了一大半。对于身材、服装、角色外观等训练目标，这种偏科同样会影响数据覆盖。

所以这里会把几个问题分开看：

```text
图片是否基本可用
→ 人脸与整图质量
→ 近重复
→ 头部角度
→ 景别 / 身体可见范围
→ 人工确认
```

软件负责把问题暴露出来，不替你定义什么才是“最好的训练集”。

## 快速开始

### 整理人物训练数据集

1. 选择图片目录并完成初始分析。
2. 先处理明显差图和近重复素材。
3. 看一下不同角度、景别和身体可见范围是否过于集中。
4. 根据自己的训练目标继续人工筛选。
5. 最后导出真正要用于训练的图片。

如果使用 v0.3 开发版，还可以在同一流程里继续处理组合图和自动裁剪。

人物一致性、表情、服装、姿态、身材、画面风格，以及你希望最终模型学到什么，仍然需要自己判断。

### 清理字幕 / 水印

选择输入目录后，程序会检测文字区域。你可以修改检测框，选择修复方式，先看预览，再批量输出到新目录。

如果文字正好覆盖眼睛、五官或其他重要训练特征，很多时候直接不用这张图会比强行修复更合适。

## 分析用了什么？

Face LoRA Dataset Selector 没有依赖一个“万能评分模型”，不同问题由不同方法处理：

| 用途 | 方法 |
| --- | --- |
| 人脸检测 | YuNet |
| 人脸质量 | eDifFIQA-T |
| 整图质量 | BRISQUE |
| 头部姿态 / Yaw | 3DDFA-V2 |
| 身体关键点 / 景别辅助 | MediaPipe Pose |
| 近重复 | pHash + 质量排序 |
| 文字区域检测 | PP-OCRv5 |

这些指标负责提供信息和候选排序，不会单独决定一张图片最终该不该进入训练集。

相关项目与资料：

- [eDifFIQA](https://github.com/LSIbabnikz/eDifFIQA)
- [BRISQUE / OpenCV Quality](https://docs.opencv.org/4.x/d8/d99/classcv_1_1quality_1_1QualityBRISQUE.html)
- [3DDFA-V2](https://github.com/cleardusk/3DDFA_V2)
- [YuNet / OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)
- [MediaPipe Pose Landmarker](https://developers.google.com/mediapipe/solutions/vision/pose_landmarker)

## 会不会动原图？

大多数工作流不会覆盖原始图片。

分析结果、筛选状态、自动裁剪建议、训练导出和 Text Cleanup 修复都会保存在缓存或新的输出位置。

v0.3 中有两类操作会改变文件位置，因此会明确提示：

- 接受组合图拆分后，原组合图会移动到数据集内的隔离目录；
- 使用源文件整理时，会在确认计划后移动活动图片。

第一次使用这类文件整理功能时，建议先用数据集副本熟悉流程。

## 模型下载与缓存

大部分基础功能所需的模型会随程序提供。

少数可选功能会在第一次使用时按需下载模型，例如 MI-GAN。下载完成后会校验并保存到 FaceLoRA 的模型缓存中，后续可以继续复用。

可选模型下载失败不会影响与它无关的其他功能。

## 当前适用范围

目前最适合的是 **以真人 / 人物图片为主要素材的数据集**。

它不只用于人物身份或人脸训练。身份、人脸、身材、体型、服装造型、角色外观，以及以人物为主体的风格训练，都可以使用其中一部分或完整流程。

不过，部分自动指标本身仍然围绕人脸和人体设计。例如 eDifFIQA-T、Yaw / Pitch 在人脸清晰可见时最有参考价值。对于完全不依赖人物信息的纯场景、产品或其他数据集，这些指标未必合适。

复杂杂志版式、网页拼贴和扫描页也不是当前重点。如果素材结构很复杂，仍建议先人工整理，再进入筛选流程。

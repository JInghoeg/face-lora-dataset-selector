## 它能做什么？

**轻量、本地、解压即用**

Windows 本地运行，下载解压即可使用。

**自动推荐**

只需选定文件夹，并设定好目标数量，即可通过评分与推荐系统自动批量推荐图片。

**快速分析**

采用轻量、成熟的分析方案，大批量素材也能快速完成处理。

**科学的筛选系统**

参考权威公开研究、论文和经过验证的模型，结合 AI 训练需求进行评分、排序与推荐。后续版本会持续调整迭代。

**高效手动筛选**

快速方便地调整挑选结果，自由决定最终选择。

**组合图自动拆分**

自动识别多人物、多视角和拼接图片，并生成拆分结果供快速确认。

**自动裁剪**

自动识别人物主体，并裁掉图片中的无效区域，支持人工确认和调整裁剪范围。

**批量自动去文字 / 水印**

自动批量检测图片中的文字和水印区域，支持预览、人工调整和批量处理。

**非破坏性文件操作**

处理结果与原始数据分离，不直接覆盖原始图片。

## 适合什么场景？

Face LoRA Dataset Selector 主要面向 **以人物 / 人像图片为训练素材的数据集**，当前版本更推荐用于 **真人，以及写实或偏写实的 CG 人物素材**。

典型用途包括：

- 真人、人物身份 LoRA；
- 人脸特征相关训练；
- 身材、体型、身体比例相关训练；
- 服装、造型、角色外观 LoRA；
- 写实或偏写实 CG 角色训练；
- 以人物为主体的摄影、视觉风格训练；
- 其他需要人物图片筛选、去重、裁剪和整理的数据集。

它既可以用于第一次准备自己的训练集，也适合已经有固定筛选习惯，希望减少重复工作的用户。

当前部分分析指标围绕人脸和人体设计。对于纯场景、产品或完全不依赖人物信息的数据集，人脸质量、头部姿态和景别等指标的参考价值会明显降低。

## 推荐的数据集整理流程

一套人物训练数据集通常会经过多轮整理。

目前推荐的顺序是：

```text
分析
 ↓
初筛
 ↓
去重
 ↓
拆分
 ↓
筛选
 ↓
AI 辅助复核（可选）
 ↓
裁剪
 ↓
整理
 ↓
导出
```

文字 / 水印处理是独立流程，可以根据素材情况在需要时使用。

### 1. 分析

选择素材目录后，对图片进行批量分析。

当前会整理的信息包括：

- 图片质量；
- 人脸质量；
- 人脸大小；
- 头部 Yaw / Pitch / Roll；
- 景别；
- 身体可见范围；
- 近重复关系；
- 其他用于评分和排序的数据。

分析结果会保存下来。之后重新打开同一个数据集时，没有变化的图片可以直接复用已有结果。

### 2. 初筛

根据设定的目标数量和自动推荐结果，先从大量素材中得到一批更值得继续检查的图片。

这一阶段主要用于快速减少明显质量较差、大量重复或价值较低的素材，不需要一开始就逐张精细判断。

### 3. 去重

对连拍、视频抽帧、写真图集等来源中的近重复图片进行集中复核。

同一个重复组可以直接比较，不需要在整个文件夹里来回寻找相似图片。

### 4. 拆分

遇到多人、多视角或拼接素材时，可以进入组合图拆分流程。

程序会生成拆分结果供人工确认，确认后的素材再进入后续分析和筛选。

### 5. 筛选

完成去重和拆分后，再根据自己的训练目标做更精细的选择。

这时可以结合：

- 图片质量；
- 人脸质量；
- 角度；
- 景别；
- 身体可见范围；
- 表情；
- 服装；
- 姿态；
- 身材；
- 场景；
- 整体数据分布；

继续调整最终保留的素材。

### 6. AI 辅助复核（可选，v0.3）

如果希望再多一层检查，可以导出 **AI Review Bundle**，交给 GPT 等具备图像理解能力的大模型辅助复核。

大模型可以结合图片和已有分析结果，对人物一致性、异常素材、重复感、构图、训练价值等方面给出进一步建议。

复核结果可以再导回程序，作为独立的建议层供人工参考，不会直接覆盖原有筛选结果，也不会替用户决定最终训练集。

### 7. 裁剪

对构图不理想、主体占比不足或画面包含较多无效区域的图片，可以使用自动裁剪。

程序会识别人物主体并生成裁剪建议，之后可以直接确认、保留原图或手动修改裁剪范围。

### 8. 整理

筛选完成后，可以根据最终状态整理当前数据集中的素材。

整理属于显式文件操作，执行前会显示计划，并进行冲突检查。

### 9. 导出

最后将确认后的图片导出到新的训练集目录。

原始素材与最终输出分开保存。

## 文字 / 水印处理

文字和水印处理是独立流程，可以根据素材情况选择使用，不要求出现在主流程的固定位置。

选择图片目录后，程序会批量检测图片中的文字区域，并给出建议修复框。自动检测和建议用于减少人工工作量，仍可能存在误检或漏检，建议在批量处理前进行人工复核。

检测完成后可以：

- 查看全部图片，或只看“需要修复 / 有文字 / 人工修改”的图片；
- 勾选或取消具体修复区域；
- 手动补画漏检区域；
- 删除误识别区域；
- 预览修复效果；
- 使用 AI 修复、TELEA 或 Navier-Stokes；
- 批量输出处理结果到新目录。

### 当前版本操作提示

**翻页**

结果列表当前每页最多显示 **80 张**。图片较多时，翻页按钮和“第几页 / 总张数”位于列表底部。

“全部图片”模式会保留没有检测到文字的图片，因此可能看到 `检测 0 · 建议 0`。这是为了让漏检图片仍然可以人工补框；如果只想复核有结果的图片，可以切换到“仅显示需要修复”或“仅显示有文字”。

卡片上的“检测”数量会受到 **最小高度、最小面积、最低置信度** 三个筛选参数影响。

**手动补框**

1. 在左侧列表中选择图片；
2. 点击顶部的 **“添加区域：关”**，切换为 **“添加区域：开”**；
3. 在右侧大图上按住鼠标拖出矩形区域；
4. 松开后，新区域会加入修复列表并默认勾选。

当前版本还不能直接拖动或缩放已有检测框。如果自动框位置不合适，请先在区域列表中选中它并删除，再使用“添加区域”重新绘制。

目前同时提供传统图像修复和 AI 修复方案，可以根据图片内容自行选择。处理后的图片输出到新的位置，不覆盖原始素材。

如果文字正好覆盖眼睛、五官、服装细节或其他重要训练特征，仍建议先判断这张图片是否值得继续保留。任何修复方法都无法保证完整恢复原本不存在的图像信息。

## 自动推荐是怎么工作的？

项目不会依赖单一指标决定图片的最终价值。

当前分析会分别处理几个不同的问题，例如：

- 有没有足够清晰、足够大的脸；
- 人脸本身的质量；
- 整张图片的视觉质量；
- 人物头部朝向；
- 人物在画面中的身体可见范围；
- 图片之间是否高度相似。

这些结果会共同参与评分、排序和推荐。

例如，一张非常清晰的正脸照片本身质量很好，但如果数据集中已经有大量相似正脸，它的训练价值未必高于一张质量稍低、但能补充侧脸或全身信息的图片。

推荐系统会根据实际训练经验、公开研究和后续验证结果持续调整。

## 当前使用的分析方法

项目优先选择公开资料充分、经过研究或实际工程验证，同时适合本地批量处理的方法。

| 分析内容 | 当前方法 | 主要用途 |
| --- | --- | --- |
| 人脸检测 | **YuNet** | 检测人脸并获取人脸位置与大小 |
| 人脸质量 | **eDifFIQA-T** | 评估人脸图像质量 |
| 整图质量 | **BRISQUE** | 无参考图像质量评估 |
| 头部姿态 | **3DDFA-V2** | 估计 Yaw / Pitch / Roll |
| 身体关键点 | **MediaPipe Pose** | 辅助判断身体可见范围与景别 |
| 近重复 | **pHash + 质量信息** | 查找视觉上高度相似的图片 |
| 文字检测 | **PP-OCRv5** | 检测字幕、水印和其他文字区域 |

这些方法负责不同的任务，不会由任何一个模型单独决定最终筛选结果。

相关资料：

- [eDifFIQA](https://github.com/LSIbabnikz/eDifFIQA)
- [YuNet / OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)
- [BRISQUE / OpenCV Quality](https://docs.opencv.org/4.x/d8/d99/classcv_1_1quality_1_1QualityBRISQUE.html)
- [3DDFA-V2](https://github.com/cleardusk/3DDFA_V2)
- [MediaPipe Pose Landmarker](https://developers.google.com/mediapipe/solutions/vision/pose_landmarker)

## 分析效率与质量

项目在分析方案的选择上同时关注 **速度、资源占用和结果质量**。

当前主要使用适合本地批量处理的轻量成熟模型，在保持较高分析质量的同时，让几百甚至更多图片的处理速度保持在实用范围内。

已经分析过的图片会保存结果。重新打开同一个数据集或继续处理时，没有变化的素材无需重新执行完整分析。

后续如果能够在 **保持高效快速和高质量分析** 的前提下进一步提升性能，预计会加入 GPU 加速。

## 人工筛选与自动结果

程序中的推荐、备选和淘汰状态都可以人工修改。

如果你已经有自己的训练经验，可以直接参考质量、角度、景别、重复关系等分析信息，然后按照自己的规则继续筛选。

不同训练目标往往会有不同的数据取舍。

例如：

- 身份 LoRA 可能更关心脸部一致性和角度；
- 身材相关训练会更关注身体完整度和全身素材；
- 服装 LoRA 需要保证服装主体足够清楚；
- 风格训练可能更关注画面整体特征。

最终训练集始终由用户自己确认。

## AI 辅助复核

v0.3 提供 AI Review Bundle，可以把当前数据集中的稳定 ID、已有分析信息和复核所需内容导出，交给 GPT 等具备视觉理解能力的大模型继续检查。

它适合用于补充人工筛选，例如：

- 查找可能遗漏的异常图片；
- 检查人物一致性；
- 发现人工不容易注意到的相似素材；
- 从训练目标出发重新检查构图和内容；
- 对当前筛选结果给出第二轮建议。

大模型返回的结果会作为**建议层**导回，不直接修改自动推荐，也不会覆盖人工选择。

因此 AI 辅助复核可以按需要加入流程，也可以完全不使用。

## 组合图自动拆分

人物数据集经常会遇到：

- 多宫格写真；
- 多视角拼接；
- 多人物合照；
- 同一张图片里同时出现多个可用主体。

组合图拆分会自动分析这类素材并生成拆分结果，再交给用户确认。

确认后的输出会作为新的活动素材进入数据集，不需要手动打开图片编辑软件逐张裁图。

复杂杂志排版、网页截图和大量 UI 缩略图并不是当前主要处理目标，这类素材仍可能需要人工预处理。

## 自动裁剪

自动裁剪主要用于处理主体周围存在较多无效区域、人物占比过低或构图不适合直接训练的图片。

程序会识别人物主体并给出裁剪范围。

复核时可以：

- 接受自动裁剪；
- 保留原图；
- 手动拖动或缩放裁剪框；
- 重置裁剪结果。

自动裁剪本身不会修改源图片。

最终确认的裁剪结果会在训练集导出时生成。

## 数据整理

筛选完成后，可以选择继续整理原始素材目录。

Source Organizer 会根据当前筛选状态生成文件移动计划，例如将素材整理到不同状态目录。

真正执行前会先进行：

- 操作预览；
- 路径冲突检查；
- 用户确认。

如果执行过程中出现问题，也会进行相应的回滚处理。

这一步是可选的。如果只需要导出训练集，可以完全不整理原始素材目录。

## 非破坏性文件操作

项目默认将分析状态和处理结果与原始图片分离。

不会直接覆盖源图片的操作包括：

- 数据分析；
- 自动推荐；
- 人工筛选状态；
- 自动裁剪；
- AI 辅助复核；
- 文字 / 水印处理；
- 最终训练集导出。

少数确实需要移动文件的功能会明确提示。

当前主要包括：

- 确认组合图拆分后，对原组合图进行隔离；
- Source Organizer 整理活动数据集。

这些操作不会在后台静默执行。

## 模型与缓存

部分基础模型会随程序一起提供。

少数体积较大或可选的功能模型会在第一次使用时按需下载，并在下载后进行完整性校验。

已经下载的模型会保存在本地缓存中，之后继续使用或升级程序时可以复用。

图片分析结果同样会缓存，因此再次打开已有数据集时，不需要从头重新处理所有图片。
